# Automation Projects

Standalone automation scripts — each one a small, self-contained pipeline (fetch/generate → transform → act) rather than a managed data platform component. Where the sections above show production data infrastructure, this section shows applied scripting: API orchestration, LLM-driven content generation, and scheduled bots.

- [`reddit_ai_assistant_bot/`](reddit_ai_assistant_bot) — Monitors a subreddit for question posts and auto-replies with a link to a custom GPT assistant
- [`ai_generated_hybrid_animals/`](ai_generated_hybrid_animals) — LLM-directed image generation pipeline that creates and auto-posts AI-generated hybrid-animal art to social media
